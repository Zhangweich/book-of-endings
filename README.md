# 终局之书 · The Book of Endings

我们比之前的任何时刻都更接近终局时刻。

我们希望《终局之书》成为一场众包的、关于人类终局的讨论：一本永远无法写完、由所有人共同编写的书。

- 每个人都可以 fork 这本书，写出自己的版本。
- 每一次投票和选择都应该被计数。
- 每个人都可以修改自己的选择，添加自己的选项。
- 贡献者可以留下昵称和邮箱。

---

We are closer to the moment of ending than at any time before.

We hope The Book of Endings becomes a crowd-sourced discussion about humanity's endings: a book that can never be finished, written by everyone together.

- Anyone can fork the book and write their own version.
- Every vote and every choice should be counted.
- Everyone can change their choices and add their own options.
- Contributors can leave a nickname and an email.
