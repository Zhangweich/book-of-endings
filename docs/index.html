人类的可能终局与分支 · 1—5 个世纪

我们比之前的任何时刻都更接近终局时刻。

愿景我们希望《终局之书》成为一场关于人类终局的讨论：一本永远无法写完、由所有人共同编写的书。

  • 每个人都可以创建自己的线路，提出自己的想法。
  • 每一次投票和选择都被计数。
  • 每个人都可以修改自己的选择，添加自己的选项。
  • 书中的每一条线路，都会记下提出和调整它的贡献者。

共同规则

共同写作，
也共同承担。

尚未经社区表决批准

01 / 署名负责

每次表达，都有一个负责的人。

可以使用真实姓名或持续化名，无须公开法定身份。最终提案、论证与表态由提出者本人审阅并负责。当前的分支框架与各节点说明尚无社区认可，不能冒充已经达成的共识。

02 / 论证先于票数

分清三个不同的问题。

什么可能发生？讨论条件、机制和证据。

我们希望什么发生？说明价值选择和受影响的人。

共同版本收录什么？按公开程序决定怎样编辑。

表决是编辑与治理的一部分，不会把一种叙事变成事实。账户投票不等于唯一自然人投票；当前方案未实现一人一票。

03 / 透明审议

把过程和理由一起留下。

  1. 提出修改署名、修改前后内容、证据和反对意见。
  2. 公开讨论 · 至少 7 天实质修改补全材料后开始；治理流程修订至少讨论 14 天。
  3. 冻结版本并表态 · 至少 72 小时指定完整 commit、规则版本和 UTC 时段；以附理由的公开评论记录支持、反对或弃权。
  4. 公开结算与纠错 · 至少 48 小时一般实质修改需至少 3 个有效非提案者账号参与，支持占支持与反对合计至少三分之二；弃权不进入支持比例。可能改变结果的争议必须先解决。
  5. 执行或继续分叉维护者按决议执行并保留少数意见；未达门槛保持待议，不自动批准。

规则由维护者人工执行，模板不自动计票。Discussions Poll 与 emoji 仅作非正式反馈。初版网站是发起人提供的讨论起点，不计作社区表决通过。

04 / 保留异议

不必赢得多数，才值得被保存。

善意的反对理由、未通过提案和替代路径应保留原始链接与版本。共同版本需记录少数意见，独立 Fork 可以继续发展。作者不应被他人代为宣布“异议已解决”。

骚扰、威胁及隐私泄露不受此保护；处理违规时应留下不再次暴露隐私的理由和可行申诉路径。平等参与、隐私与少数意见保护不能由一次简单多数表决直接取消。

05 / 开放与可修订

这本书，也包括它的规则。

初始维护者仍拥有技术管理权限，Git 历史也不是绝对不可更改的档案。独立保存、公开记录与多方维护，是减少对单个人依赖的起点。

当前没有真实社区提案、选票或独立分叉。
